# 🧭 Navigation Bar Project

This project demonstrates how to create clean and functional navigation menus for modern websites.

### 🚀 Key Features:
- **Responsive Design:** Adapts to different screen sizes.
- **Flexbox Layout:** Using CSS Flexbox for perfect alignment.
- **Hover Effects:** Smooth transitions and opacity changes.
- **Sticky Header:** Keeping the menu visible while scrolling.

### 🛠 Technologies Used:
- **HTML5:** For semantic menu structure.
- **CSS3:** For styling, positioning, and animations.
